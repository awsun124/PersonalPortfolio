# Personal Portfolio

My personal portfolio website, built with React, TypeScript, Vite, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

The local site runs at `http://localhost:8080`.

## Project structure

- `src/components/home` contains the homepage sections.
- `src/components/projects` contains shared project-page components.
- `src/data/projects.ts` is the source for homepage project cards.
- `src/pages` contains routed pages and project content.
- `src/assets` and `public` contain images, documents, and videos.

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```
